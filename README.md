# Music Venues Collector

Collecte automatisée des données des salles de concert et festivals en France.

## Installation

1. Cloner le repository
2. Créer un environnement virtuel Python
3. Installer les dépendances
4. Configurer les credentials Firebase

## Structure

```
├── credentials/         # Stockage des credentials (non versionné)
├── src/                # Code source
│   ├── scrapers/       # Scripts de scraping
│   ├── database/       # Gestion de la base de données
│   └── utils/          # Utilitaires
├── logs/               # Fichiers de logs
└── tests/              # Tests unitaires
```
